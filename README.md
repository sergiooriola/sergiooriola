# Sergio Oriola

AI engineer in Madrid. I build LLM agents and the software around them in Python and
TypeScript, from requirements to production.

Telecommunication Engineer (BEng and MSc, Universidad Politécnica de Madrid), specialised
in AI and machine learning. I work freelance on websites, integrations and automations
for non-technical clients.

## Currently building

- **[citedesk](https://github.com/sergiooriola/citedesk)**: an open-source assistant
  engine that answers only from approved entries, cites the entry behind every answer and
  hands everything else to a person. Pre-alpha, built in the open from the first commit.

## Selected work

- **[agentic-rag-assistant](https://github.com/sergiooriola/agentic-rag-assistant)**:
  conversational RAG agent in LangGraph. Hybrid retrieval (BM25 + embeddings fused with
  RRF), answers with source citations, and a groundedness check that refuses instead of
  guessing. FastAPI, Docker, tests and CI.
- **[Evaluation framework for hybrid quantum-classical ML](https://github.com/sergiooriola/hybrid-qml-evaluation)**:
  my master's thesis. Benchmarks six variational quantum classifiers against six
  classical baselines under class imbalance: 2,880 reproducible runs and a statistical
  protocol fixed in advance.
- **[AI tutor for UPM's Insignia project](https://github.com/sergiooriola/pie-insignia-agent)**:
  agent built with the OpenAI Agents SDK and RAG over the course documents. FastAPI
  backend, React and TypeScript frontend, Supabase for sign-in and chat logs.
- **[Dragon American School](https://colegioamericanodragon.com)** (private repository):
  140-page bilingual website in Astro and TypeScript that I built and run in production,
  with a family area and forms on Supabase.
